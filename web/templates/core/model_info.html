Model Information

Stacking Ensemble Architecture

The prediction system uses a two-level stacking ensemble that combines three heterogeneous base learners with a logistic regression meta-learner. Out-of-fold (OOF) predictions are used during meta-learner training to prevent data leakage.

Level 0: Base Learners

XGBoost

Regularized gradient boosting. Tuned: n_estimators=500, max_depth=5, lr=0.05.

SVM (Calibrated)

RBF kernel with StandardScaler pipeline. Calibrated via isotonic regression for probability outputs.

Random Forest

500 estimators, balanced class weights. Diverse from boosting models for ensemble diversity.

Level 1: Meta-Learner

Logistic Regression

Combines 9 probability outputs (3 per base model) into final prediction.

  • class_weight: balanced
  • solver: lbfgs
  • max_iter: 5000
  • OOF training to prevent leakage
