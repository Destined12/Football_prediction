Methodology

1. Data Collection & Preprocessing

  • • Historical match data collected from football-data.co.uk
  • • 6 seasons merged and sorted chronologically (2019-2025)
  • • All betting odds columns excluded to prevent data leakage
  • • Duplicates removed, dates standardized, missing values handled

2. Feature Engineering

  • • 198 features engineered across 15+ categories (form, performance, H2H, Elo, dominance, momentum, etc.)
  • • Strict anti-leakage: features computed only from historical matches before the fixture
  • • Rolling windows for team form (last 5 matches)
  • • Head-to-head features computed from past meetings only

3. Feature Selection

  • • Correlation analysis to remove redundant features (|r| > 0.90)
  • • SHAP-based feature importance ranking
  • • 50 features selected from 157 (after correlation filter) via SHAP ranking + TimeSeriesSplit CV

4. Model Training

  • • Chronological train/test split (2019-2024 train, 2024-2025 test)
  • • Three heterogeneous base learners: XGBoost, SVM (with StandardScaler), Random Forest
  • • Meta-learner: Logistic Regression with balanced class weights (OOF stacking to prevent leakage)
  • • Stacking: 9 probability features from base models (3 each) fed into meta-learner

5. Model Evaluation

  • • Accuracy, Precision, Recall, F1, ROC-AUC, Log Loss, Balanced Accuracy
  • • Confusion matrix analysis for each model
  • • SHAP explainability for feature-level prediction interpretation
