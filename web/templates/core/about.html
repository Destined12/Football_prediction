About This Project

Project Overview

This system is developed as an undergraduate project titled "Development of a Web-Based Football Match Prediction System Using a Stacking Ensemble Machine Learning Model." It predicts English Premier League match outcomes using historical match statistics from the 2019-2020 through 2024-2025 seasons.
